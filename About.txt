
The Fantastically Useful Color Komparator is a program that takes two colors inputted by
the user, and then compares them to see how they can be seen by different types of colorblindness!

This program can accept two different types of colors measured in RGB values (Red, Green, Blue), a 
system that utilizes values from 0 to 255 for all three of the values. Then, it can evaluate these
colors on different types of colorblindness:

Protanomaly
Deuteranomaly
Tritanomaly
Protanopia
Deuteranopia
Tritanopia
Monochromacy

Feel free to use this program to your liking!
