# COLOR VISION PROJECT

## Description

**version 1.0**

This is a program that discerns a color from three values, symbolizing RGB (Red/Green/Blue).
Enter three values, and the program will discern the combination!
It will allow you to process the color combination through seven types of colorblindness.

## Example

Here is an example of the program running:
Enter three numbers (Red/Green/Blue) from a range of 0 to 255. Press Enter after each value: 
255 <- Red Value
0 <- Green Value
0 <- Blue Value
Success! Looks like your chosen color is Mostly Red.
This is a color that can be perceived differently by people with colorblindness.
Would you like to see which types will perceive your color differently? (Y/N) Y
There are multiple types of colorblindness a person can have. I can evaluate your chosen color based on different types of colorblindness.I am able to evaluate seven of them: 
1. Deuteranomaly (Green-Weak)
2. Protanomaly (Red-Weak)
3. Tritanomaly (Blue-Weak)
4. Deuteranopia (Green-Blind)
5. Protanopia (Red-Blind)
6. Tritanopia (Blue-Blind)
7. Monochromacy (True Colorblindness)
Enter a value from 1-7 to evaluate your color based on different blindness types: 2

You have chosen: Protanomaly
Protoanomaly is another common form of colorblindness, seen in 1.03% of people.
Reds appear darker and duller, with oranges and yellows looking very similar to them.
Because it dims the reds in our daily lives, red lights, brakes, and danger text can be hard to spot.
Your color may pose a problem with those with Protoanomaly.
It will cause your color to be dimmed in their eyes.
Create more contrast in your color. Make the color a little bit more orange, and avoid making the reds and greens too similar.
Thank you for assessing colors today! I'll see you later!
